BFS กับ DFS ต่างกันอย่างไร

    

      

        
BFS — ทีละระดับ

        
ใช้ Queue (เข้าก่อนออกก่อน) เยี่ยมจุดที่ใกล้ Start ก่อน จึงการันตีว่า Path ที่ได้ผ่านจำนวน Edge น้อยที่สุด ตัวอย่าง: Start → SQL → Backend Developer

      

      

        
DFS — ลึกสุดก่อน

        
ใช้ Stack (เข้าหลังออกก่อน) ไล่ลงไปจนสุดสายแล้วค่อยย้อนกลับ ได้ Path ที่ถูกต้องแต่ไม่การันตีว่าสั้นที่สุด เช่น Backend Developer อาจถูกพบผ่าน HTML → CSS → JavaScript → Node.js

      

    

    
BFS และ DFS ไม่สนน้ำหนักของ Edge — ถ้าอยากได้เส้นทางที่ใช้เวลาเรียนน้อยที่สุด ให้ไปหน้า 3 ซึ่งใช้ Weighted Graph และ Dijkstra
