Root Parent / Child Leaf Path ที่เลือก

คลิกโหนดใดก็ได้เพื่อกระโดดไปที่ตำแหน่งนั้น — เส้นสีส้มคือ Path จาก Root ถึงโหนดปัจจุบัน

Tree Traversal Bonus

เลือกวิธีเดินผ่านต้นไม้ แล้วดูลำดับการเยี่ยมบนแผนภาพด้านบน

Tree นี้แทนอะไรในระบบ

โครงสร้างการตัดสินใจ

แต่ละโหนดที่มี Child คือ “คำถาม” และ Child แต่ละตัวคือ “ตัวเลือก” ผู้ใช้จึงไม่ต้องเห็นอาชีพ 12 อย่างพร้อมกัน แต่ตัดสินใจทีละ 2–3 ตัวเลือก

หมวดหมู่ 4 ระดับ

Root = ทุกอาชีพ → หมวดใหญ่ 3 หมวด → สาขา 6 สาขา → อาชีพ 12 อย่าง (Leaf) ทุก Leaf อยู่ที่ Level 3 เท่ากัน

Leaf ของ Tree คือ Vertex “อาชีพ” ตัวเดียวกันในกราฟทักษะ (หน้า 2–3) ผลลัพธ์จึงส่งต่อไปคำนวณเส้นทางเรียนรู้ได้ทันที
